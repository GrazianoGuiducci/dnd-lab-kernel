# One continuing relation, replaceable means

```text
operator, sources and available possibilities
                 ↕
semantic kernel ↔ cognitive receiver ↔ competences and their evolution
                 ↕
temporary contact → occurrence → exact deposit
                 ↘ retained knowledge / reachable field effects
                         ↘ following contact and reentry
```

The arrows express causal relationships, not mandatory scientific phases.
Research and monitoring can change the next question and the way it is formed.
The host can work through its own tools or the supplied local incarnation.

The local incarnation has these responsibilities:

| Relation | Incarnation |
|---|---|
| Own identity and continuity | A new lab_id and SQLite state in the receiver's directory |
| Attributed sources and versions | Canonical JSON, source owner and related IDs; prior versions retained |
| Temporary attention | Explicit focus or content-addressed traversal of unobserved source contacts |
| Reachable horizon | Compact index plus source/competence/event lookup; uncontacted content stays outside attention |
| Regenerative return | Exact event plus optional retained knowledge, cooling and reachable field effects |
| Reentry | Reopen the same state in a fresh process; methods remain available |
| Changed conditions | Compare-and-deposit in one transaction; changed source/memory/contract invalidates stale contact |
| Monitoring | Observe JSON snapshots, optionally call the receiver's configured cognitive bridge |
| Concrete effects | Provider bridge and host-owned tools have their own authority; event payloads run no commands |
| Cognitive entry identity | Source-native or installed AGENTS/BOOT/KERNEL/CONCEPTS/COMPETENCES enter the same contact contract |
| Bounded output collection | Concurrent pipe draining, bounded stdout storage, counted/discarded stderr, direct-child interruption on limit |

The three required occurrence fields are schema, bound event_id and non-empty
resultant. Open optional carriers stay in the event even when this tool does
not materialise them. Arbitrary source/resultant keys do not become runtime
configuration. Retention is a receiver declaration; the implementation cannot
decide whether knowledge is true or whether a model has learned.

Successful contact identity uses active source versions, contacted memory,
intent, kernel contract and profile. It excludes clocks, wake labels and
uncontacted source changes. Content addressing is exact canonical identity,
not a semantic similarity metric. The receiver selects relevance and meaning.

SQLite transactions atomically receive an event and update its derived index.
Triggers protect event and source rows from ordinary UPDATE/DELETE. They are
not a security boundary against the database owner. No private original
runtime, memory, prompts or host services are dependencies of this package.

Initial executable scope: local JSON/text sources, declared source relations,
explicit or source-bound competence contact, open resultants, selective memory,
finite observation loops and stdio cognition. Native host interaction can
extend that scope. A web dashboard, arbitrary tool execution inside the
contained bridge protocol and deployment to an operational host are separate
incarnations; none is silently installed here.
